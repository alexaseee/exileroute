# PoE Act Overlay

**[Скачать установщик для Windows](https://github.com/alexaseee/poe-act-overlay/releases/latest/download/PoEActOverlay-Setup.exe)**

Оверлей показывает задачи и маршрут для текущего акта Path of Exile 1. Требуются Windows 10 или 11 x64 и .NET Framework 4.8 или новее.

## Быстрый старт

1. Запустите установщик, затем откройте **PoE Act Overlay** из меню «Пуск». В игре включите оконный режим без рамки.
2. Проверьте статус журнала в редакторе. Если автопоиск его не нашёл, нажмите **Выбрать…** и укажите файл `logs\Client.txt` из папки игры.
3. Выберите профиль **Основной** и вкладку **Маршрут**. Если оверлей показывает задачи, нажмите **Маршрут** и в самом оверлее.
4. Нажмите **К игре**. Оверлей будет переключать акт при переходах между локациями. Хоткей `Ctrl+Shift+9` включает и выключает режим **Сквозь**.

Чтобы изменить готовый маршрут, добавить задачи и отмечать выполнение, сделайте копию профиля **Основной**.

## Исходный код

`build.cmd` собирает приложение. `.\build-installer.ps1` собирает установщик с NSIS 3.
