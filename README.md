# ExileRoute

**[Скачать установщик для Windows](https://github.com/alexaseee/exileroute/releases/latest/download/ExileRoute-Setup.exe)**

Оверлей показывает задачи и маршрут для текущего акта Path of Exile 1. Требуются Windows 10 или 11 x64 и .NET Framework 4.8 или новее.

## Быстрый старт

1. Запустите установщик, затем откройте **ExileRoute** из меню «Пуск». В игре включите оконный режим без рамки.
2. Проверьте статус журнала в редакторе. Если автопоиск его не нашёл, нажмите **Выбрать…** и укажите файл `logs\Client.txt` из папки игры.
3. Выберите **Основной** или **Exile Leveling** в списке профилей. Если оверлей показывает задачи, нажмите **Маршрут** в самом оверлее.
4. Нажмите **К игре**. При переходе в локацию, которая есть в маршруте, оверлей прокрутит список к ней и покажет метку **«Вы здесь»**. Хоткей `Ctrl+Shift+9` включает и выключает режим **Сквозь**.

Оба маршрута встроены в приложение и доступны офлайн. Чтобы изменить маршрут, добавить задачи и отмечать выполнение, нажмите **Копировать** у выбранного профиля.

## Исходный код

`build.cmd` собирает приложение. `.\build-installer.ps1` собирает установщик с NSIS 3.
